1. Структура плагина

Плагин — это единый .js файл, а метаданные указываются в комментариях строго в начале файла, до любого исполняемого кода.

Core rules 
// @name Название Плагина
// @author Ваш Ник
// @version 1.0
// @description Подробное описание того, что делает ваш плагин.
// @banner https://funpay.tools/default-banner.jpeg

fpt.app.log("Плагин успешно инициализирован!");
Критично для генерации кода

Нельзя придумывать поля @id, вызывать fpt.plugin.register(...), использовать fpt.init(...) или ссылаться на несуществующий объект fpt.config. Также запрещено вручную объявлять PLUGIN_ID и PLUGIN_SLOT_KEY — их внедряет ядро.

ЗапрещеноПочему
// @id anythingПоля @id не существует; уникальный идентификатор создаёт ядро.
var PLUGIN_ID = "..."PLUGIN_ID уже доступен глобально, переобъявление ломает совместимость.
var PLUGIN_SLOT_KEY = "..."Нельзя переобъявлять ключ слота; готовое значение уже передаётся плагину.
fpt.plugin.register(...)Такого метода нет; плагин просто выполняется как обычный скрипт.
fpt.init(...)Метод отсутствует в API.
fpt.config.*Для настроек плагина нужно использовать fpt.storage.

2. События

Плагины могут подписываться на системные события через fpt.on(...) и реагировать на сообщения, заказы, переключение аккаунтов и состояние приложения.

Event listeners 
fpt.on("onNewMessage", function(msgData) {
    if (msgData.isMe) return;
    fpt.app.log("Новое сообщение в чате " + msgData.chatId + ": " + msgData.text);

    if (msgData.text === "!ping") {
        fpt.chat.send(msgData.chatId, "Pong!");
    }
});

fpt.on("onNewOrder", function(orderData) {
    fpt.app.log("Новый заказ " + orderData.orderId + " от " + orderData.buyerName);
});

4. Server-Driven UI

Плагин может рендерить свой интерфейс в карточке настроек приложения через fpt.ui.setSlot(PLUGIN_SLOT_KEY, ui) и управлять состоянием через getState и setState.

PLUGIN_SLOT_KEY only
Самые важные особенности UI

Все функции, на которые ссылаются onClick и onChange, должны быть объявлены через window, потому что код плагина заворачивается в IIFE. Для Input желательно всегда ставить singleLine: true, иначе переносы строк могут сломать нативный мост. После fpt.ui.setState(...) нужен повторный setSlot(...), если вы хотите визуально обновить поле на экране.

КомпонентКлючевые поля
Column / Rowchildren
Texttext, color, bold, fontSize
Buttontext, onClick
Switch / CheckboxstateKey, onChange, text
Inputlabel, stateKey, singleLine, onChange
Slidermin, max, stateKey, onChange
Card, Image, Spacer, DividerКонтейнеры и декоративные блоки интерфейса.
 
function renderUI() {
    var ui = {
        type: "Card",
        children: [
            { type: "Text", text: "Конфигурация", bold: true, fontSize: 16.0 },
            { type: "Spacer", size: 8 },
            { type: "Input", stateKey: "apiKey", label: "Ваш API ключ", singleLine: true },
            {
                type: "Row",
                children: [
                    { type: "Checkbox", text: "Включить мод", stateKey: "modEnabled" }
                ]
            },
            { type: "Button", text: "Сохранить", onClick: "window.saveData()" }
        ]
    };
    fpt.ui.setSlot(PLUGIN_SLOT_KEY, ui);
}

window.saveData = function() {
    var key = fpt.ui.getState("apiKey");
    var enabled = fpt.ui.getState("modEnabled") === "true";
    if (!key) return fpt.app.toast("Введите ключ!");
    fpt.ui.setState("apiKey", "");
    renderUI();
};

renderUI();

5. Расширенное API

Ultimate Tier добавляет новые возможности для интеграции в интерфейс приложения: оверлеи, контекстные меню, вкладки навигации, Compose-компоненты и расширенную систему событий.

Только для 2.0+
Совместимость

Методы fpt.overlay, fpt.contextMenu, fpt.navigation, fpt.compose и fpt.events доступны только в приложении версии 2.0+; для обратной совместимости нужно проверять наличие объекта через typeof.

fpt.overlay

Кнопки, баннеры и виджеты поверх экранов chats, orders, lots, profile, support и global.

fpt.contextMenu

Пункты для chat_message, chat_user, order_item и lot_item.

fpt.navigation

Добавление собственных вкладок в нижнюю навигацию, включая badge.

fpt.compose

Нативные диалоги, bottom sheet, snackbar и alert поверх WebView.

fpt.events

Подписки с фильтрами, отписка и кастомные события между плагинами.

// Проверка совместимости для 2.0+
if (typeof fpt.overlay !== 'undefined') {
    fpt.overlay.addButton({
        screen: "chats",
        icon: "https://example.com/icon.png",
        tooltip: "Быстрый ответ",
        position: "bottom_right",
        onClick: "window.quickReply()"
    });
}

if (typeof fpt.navigation !== 'undefined') {
    fpt.navigation.addTab({
        id: "my_plugin_tab",
        label: "Статистика",
        icon: "chart",
        badge: "3",
        onClick: "window.showStats()"
    });
}

if (typeof fpt.events !== 'undefined') {
    fpt.events.subscribe({
        event: "onBalanceChanged",
        handler: "window.onBalanceUpdate"
    });
}

6. Canvas to Image

Поскольку плагины работают внутри скрытого WebView, можно использовать <canvas> для генерации картинок, баннеров и изображений-ответов на лету.

Критический поток
Правильная цепочка работы с картинками

Внешние изображения нельзя безопасно тянуть напрямую в Canvas из-за CORS. Нужно скачивать их через fpt.network.fetchImageBase64(url), а перед отправкой через fpt.chat.sendWithImage() обязательно сохранять Base64 во временный файл методом fpt.app.saveBase64Image().

var base64Avatar = fpt.network.fetchImageBase64(avatarUrl);
var avatarImg = new Image();

avatarImg.onload = function() {
    var canvas = document.createElement("canvas");
    canvas.width = 400;
    canvas.height = 200;
    var ctx = canvas.getContext("2d");

    ctx.drawImage(avatarImg, 0, 0, 100, 100);

    var finalBase64 = canvas.toDataURL("image/png");
    var localUri = fpt.app.saveBase64Image(finalBase64);

    if (localUri) {
        fpt.chat.sendWithImage(chatId, "Вот картинка!", localUri, false);
    }
};

avatarImg.src = base64Avatar;

8. Инструкции для ИИ

Этот блок фиксирует правила, которые должны соблюдаться при генерации кода плагина, особенно если документацию использует LLM или авто-генератор.

Strict execution
ПравилоСуть
Не придумывать APIЕсли метода или UI-type нет в документе, значит его не существует.
Не объявлять PLUGIN_ID и PLUGIN_SLOT_KEYОни уже присутствуют в глобальной области видимости плагина.
Всегда использовать PLUGIN_SLOT_KEYНельзя собирать ключ слота вручную.
Никаких while(true)Для фоновой работы использовать setInterval или рекурсивный setTimeout.
Canvas и отправка картинокТолько fetchImageBase64 → Canvas → saveBase64Image → sendWithImage.
@bannerДолжен быть прямой ссылкой на изображение .png или .jpg.
window для UIЛюбой UI callback обязан быть глобальным: window.fn = function(){}.

Обновление UIПосле setState нужен повторный setSlot, иначе инпут не обновится визуально.
