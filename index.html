FunPay Tools Plugin API

Полная DAI-документация для разработки плагинов FunPay Tools. Включает базовый API (window.fpt), расширенный API 2.0+, Server-Driven UI, Canvas-пайплайн и инструкции для ИИ-генерации кода.

1. Структура плагина

Плагин — единый .js-файл. Метаданные указываются в комментариях строго в начале, до любого исполняемого кода.

Core rules 
// @name Название Плагина
// @author Ваш Ник
// @version 1.0
// @description Подробное описание того, что делает плагин.
// @banner https://funpay.tools/default-banner.jpeg

fpt.app.log("Плагин успешно инициализирован!");
Критично для генерации кода

Нельзя придумывать поля @id, вызывать fpt.plugin.register(...), использовать fpt.init(...) или ссылаться на несуществующий объект fpt.config. Запрещено вручную объявлять PLUGIN_ID и PLUGIN_SLOT_KEY — их внедряет ядро через IIFE.

ЗапрещеноПочему
// @id anythingПоле @id не существует; ID создаёт ядро.
var PLUGIN_ID = "..."PLUGIN_ID уже доступен глобально, переобъявление ломает совместимость.
var PLUGIN_SLOT_KEY = "..."Готовое значение уже передаётся плагину ядром.
fpt.plugin.register(...)Такого метода нет; плагин выполняется как обычный скрипт.
fpt.init(...)Метод отсутствует в API.
fpt.config.*Для настроек плагина используйте fpt.storage.
while(true)Блокирует WebView; используйте setInterval / рекурсивный setTimeout.

2. События

Подписка через fpt.on(eventName, callback). Диспетчеризация из нативного кода через fpt.emit(name, jsonString).

Event listeners 
fpt.on("onNewMessage", function(data) {
    if (data.isMe) return;
    fpt.app.log("Новое сообщение от " + data.username + ": " + data.text);
    if (data.text === "!ping") fpt.chat.send(data.chatId, "Pong!");
});

fpt.on("onNewOrder", function(data) {
    fpt.app.notify("Новый заказ", data.orderId + " от " + data.buyerName);
});

fpt.on("onBalanceChanged", function(data) {
    fpt.app.log("Баланс: " + data.oldBalance + " → " + data.newBalance);
});

fpt.network

Нативные HTTP-запросы через OkHttp в обход Cloudflare с сессионными cookies текущего аккаунта.

Network
Безопасность и ограничения

Запросы к funpay.com выполняются с сессионными cookies автоматически. Для сторонних URL cookie не добавляются. Недоступные схемы (file://, content://) блокируются. Небезопасные заголовки (Cookie, Authorization к чужим хостам и т.д.) фильтруются.

fpt.network.get(url, headersJson)→ {status, body}|null
GET-запрос. headersJson — JSON-объект заголовков (или {}). Возвращает {status: number, body: string}.
var res = fpt.network.get("https://funpay.com/users/123/", {});
if (res && res.status === 200) {
    fpt.app.log("Получено байт: " + res.body.length);
}
fpt.network.post(url, body, headersJson)→ {status, body}|null
POST-запрос. body — строка (JSON, form-encoded и т.д.). Content-Type укажите в headersJson.
var res = fpt.network.post(
    "https://example.com/api",
    JSON.stringify({ key: "value" }),
    '{"Content-Type": "application/json"}'
);
if (res && res.status === 200) {
    var data = JSON.parse(res.body);
}
fpt.network.fetchImageBase64(url)→ string
Скачивает изображение и возвращает его как Base64 Data URL (data:image/...;base64,...). Используйте для загрузки внешних изображений в Canvas (обход CORS).

Server-Driven UI

Полный список компонентов для построения интерфейса плагина через fpt.ui.setSlot().

PLUGIN_SLOT_KEY only
Три важных правила

1. Все функции в onClick / onChange обязаны быть в глобальном скоупе: window.myFn = function(){}.
2. Для Input всегда указывайте singleLine: true, иначе переносы строк могут сломать сохранение стейта.
3. После fpt.ui.setState() нужен повторный fpt.ui.setSlot(), чтобы компонент визуально обновился.

CheckboxstateKey: stringtext, onChange: "window.fn()"

function renderUI() {
    fpt.ui.setSlot(PLUGIN_SLOT_KEY, {
        type: "Card",
        children: [
            { type: "Text", text: "Настройки плагина", bold: true, fontSize: 16.0 },
            { type: "Spacer", size: 12 },
            { type: "Input", stateKey: "apiKey", label: "API ключ", singleLine: true },
            { type: "Spacer", size: 8 },
            { type: "Row", children: [
                { type: "Switch", text: "Включить автоответ", stateKey: "autoEnabled",
                  onChange: "window.onToggle()" }
            ]},
            { type: "Spacer", size: 8 },
            { type: "Slider", stateKey: "delaySeconds", min: 1, max: 30,
              onChange: "window.onSlider()" },
            { type: "Spacer", size: 12 },
            { type: "Divider" },
            { type: "Spacer", size: 12 },
            { type: "Button", text: "Сохранить настройки", onClick: "window.save()" }
        ]
    });
}

window.onToggle = function() {
    var enabled = fpt.ui.getState("autoEnabled") === "true";
    fpt.app.toast(enabled ? "Автоответ включён" : "Автоответ выключен");
};

window.onSlider = function() {
    var delay = fpt.ui.getState("delaySeconds");
    fpt.app.log("Задержка: " + delay + " сек");
};

window.save = function() {
    var key = fpt.ui.getState("apiKey");
    if (!key) return fpt.app.toast("Введите ключ!");
    fpt.storage.set("apiKey", key);
    fpt.storage.set("autoEnabled", fpt.ui.getState("autoEnabled"));
    fpt.storage.set("delay", fpt.ui.getState("delaySeconds"));
    fpt.app.toast("Сохранено ✓");
    renderUI();
};

Canvas to Image

Генерация изображений через <canvas> внутри WebView и отправка их в чат.

Критический поток
Обязательная цепочка

Внешние картинки нельзя тянуть в Canvas напрямую (CORS). Цепочка строго такая: fpt.network.fetchImageBase64(url) → установить как src → нарисовать на Canvas → canvas.toDataURL() → fpt.app.saveBase64Image() → fpt.chat.sendWithImage()

fpt.on("onNewOrder", function(data) {
    var chatId = data.chatId;
    var avatarBase64 = fpt.network.fetchImageBase64(
        "https://funpay.com/img/avatars/default.png"
    );

    var img = new Image();
    img.onload = function() {
        // Создаём canvas
        var canvas = document.createElement("canvas");
        canvas.width = 400;
        canvas.height = 200;
        var ctx = canvas.getContext("2d");

        // Фон
        ctx.fillStyle = "#1a1a2e";
        ctx.fillRect(0, 0, 400, 200);

        // Аватар
        ctx.drawImage(img, 20, 50, 100, 100);

        // Текст
        ctx.fillStyle = "#ffffff";
        ctx.font = "bold 24px sans-serif";
        ctx.fillText("Новый заказ!", 140, 90);
        ctx.font = "16px sans-serif";
        ctx.fillStyle = "#aaaaaa";
        ctx.fillText("от " + data.buyerName, 140, 120);

        // Сохраняем и отправляем
        var finalBase64 = canvas.toDataURL("image/png");
        var localUri = fpt.app.saveBase64Image(finalBase64);
        if (localUri) {
            fpt.chat.sendWithImage(chatId, "Получил ваш заказ!", localUri, true);
        }
    };
    img.src = avatarBase64;
});

Лимиты платформы

Строгие ограничения FunPay для сообщений и контента.

Максимум символов в сообщении2 000Считаются включая пробелы.
Максимум переносов строки20Каждый \n считается отдельно.

ИзображенияЧерез APIНельзя отправить ссылку как картинку; только через sendWithImage().

Инструкции для ИИ

Правила, обязательные при генерации кода плагина. Особенно важны при использовании LLM или авто-генераторов.

Strict execution
ПравилоСуть
Не придумывать APIЕсли метода или UI-type нет в этом документе — его не существует.
Не объявлять PLUGIN_ID и PLUGIN_SLOT_KEYОни уже присутствуют в глобальной области видимости плагина; ядро инжектирует их через IIFE.
Всегда использовать PLUGIN_SLOT_KEYНельзя собирать ключ слота вручную (например, "settings_" + PLUGIN_ID).
Никаких while(true)Для фоновой работы использовать setInterval или рекурсивный setTimeout.
Canvas и отправка картинокСтрого: fetchImageBase64 → Canvas → saveBase64Image → sendWithImage.
@bannerДолжен быть прямой ссылкой на изображение .png или .jpg.
window для UI-коллбэковЛюбой UI callback обязан быть глобальным: window.fn = function(){}.
Баг с InputПереносы строк могут ломать стейт; всегда применять singleLine: true.
Обновление UIПосле setState нужен повторный setSlot, иначе инпут не обновится визуально.
