API Documentation

Документ описывает ключевые UI-компоненты, модели данных и локальный слой хранения приложения FunPay Tools: настройки приветствий, ответы на отзывы, чат с вложениями и выделением сообщений, метки и папки, режим занятости, расписание, блоки монетизации и поддержку проекта.

Overview

Основные области

  • Настройки автоматических ответов и приветствий.
  • Работа с чатами: фильтрация, метки, папки, архив.
  • Экран переписки: выбор сообщений, медиа, поиск, перевод.
  • Режим занятости и расписание.
  • Поддержка, донаты, PRO-статусы и реклама-разблокировка.

Ключевые Compose-паттерны

  • remember и mutableStateOf для локального состояния.
  • LazyColumn для длинных списков и настроек.
  • Dialog + verticalScroll для модальных редакторов.
  • rememberLauncherForActivityResult для Photo Picker.
  • SharedPreferences + Gson для локального хранения JSON.

Storage Layer

ChatFolderManager объединяет загрузку и сохранение меток, папок, связей чатов, busy mode, flood chat и расписания через SharedPreferences.

Данные сериализуются в JSON и читаются обратно через Gson, что упрощает быстрый локальный persistence без отдельной БД.

GreetingDialog

UI/settings/greeting
  • Поле текста приветствия.
  • Поддержка переменных: $username, $chat_name, $chat_id, $date, $time, $full_date, $message_text.
  • Выбор изображения через Photo Picker.
  • Порядок вывода картинки относительно текста.
  • Кулдаун от 1 до 168 часов.
  • Игнорирование системных сообщений.

ReviewSettingsDialog

UI/settings/reviews
  • Два режима: AI и шаблоны.
  • PRO-доступ для AI-режима.
  • AI length от 1 до 10.
  • Опции: название лота, дата, стиль, инструкция, fallback.
  • Ручные шаблоны на 1–5 звёзд с включением/выключением.
  • Справка по переменным от FpPlaceholders.

Compose / Android Patterns

  • rememberSaveable и mutableStateOf используются для устойчивого UI-состояния.
  • Dialog применён для крупных настроек, которые не помещаются в основной экран.
  • LazyColumn помогает держать диалоги и настройки производительными.
  • rememberLauncherForActivityResult используется для безопасного выбора фото через Photo Picker.
  • SharedPreferences хранит пользовательские сущности и настройки без внешней базы.
  • Анимации построены через animateColorAsState, animateDpAsState и AnimatedVisibility.
